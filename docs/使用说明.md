# 猫狗图片分类使用说明

本项目使用 ImageNet 预训练 ResNet18，将原分类头替换为猫狗二分类头，并微调 `layer4` 与分类头。训练集使用随机裁剪和水平翻转，验证集使用固定缩放与中心裁剪。

## 1. 准备数据

下载并解压 Kaggle Cats vs Dogs。以下任一种目录结构均可：

也可以从 Microsoft 官方镜像自动下载：

```bash
bash scripts/download_data.sh
```

```text
data/
└── PetImages/
    ├── Cat/
    └── Dog/
```

也可直接把 `Cat/` 和 `Dog/` 放在传给 `--data-dir` 的目录下。程序会校验图片并跳过 Kaggle 数据中的损坏文件，然后按类别分层划分训练集和验证集。

## 2. 安装环境

```bash
bash scripts/setup.sh
```

依赖安装在项目的 `.venv` 中，PyTorch 使用官方 CUDA 13.0 构建。当前电脑没有可用 Bash 时，可安装 Git for Windows 后通过 Git Bash 执行这些脚本。

## 3. 训练

```bash
bash scripts/run_train.sh --data-dir data --epochs 10 --batch-size 32
```

程序自动选择 CUDA、MPS 或 CPU。RTX 4060 8GB 建议先使用默认批量大小 32；显存不足时改为 16。

训练产物位于 `outputs/`：

- `best_model.pt`：验证准确率最高的模型
- `training_curves.png`：loss 和 accuracy 曲线
- `history.json`：每轮原始指标

训练日志位于 `logs/train.log` 和 `logs/train-command.log`。

## 4. 单张图片推理

```bash
bash scripts/run_predict.sh --image path/to/test.jpg --model outputs/best_model.pt
```

推理前默认先执行 NSFW（不适宜内容）前置门禁：使用本地 `Falconsai/nsfw_image_detection`（ViT）模型给出 NSFW 概率，达到阈值即拒绝分类并以退出码 1 结束。相关参数：

- `--nsfw-threshold`：NSFW 判定阈值，默认 `0.5`
- `--nsfw-model`：替换 NSFW 模型 ID，默认 `Falconsai/nsfw_image_detection`
- `--skip-nsfw-check`：跳过门禁（仅用于调试）

首次运行会下载约 340MB 的模型权重并缓存到 HuggingFace 缓存目录（后续离线复用）。若无法直连 huggingface.co，可先设置镜像再运行：

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

终端会输出类别、置信度和一行 JSON 结果。推理日志位于 `logs/predict.log`。

## 5. 运行测试

```bash
bash scripts/run_tests.sh
```

## 6. 说明

本版本在猫狗二分类之外，增加了推理前置 NSFW 门禁。门禁只做安全拦截，不改变猫狗分类逻辑；相关依赖为 `transformers`。Oxford 17 Flowers 是 17 分类任务，需要将类别发现逻辑改为通用多类别版本后再使用。
